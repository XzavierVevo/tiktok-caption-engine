          Facebook Ads

          Connect with Facebook Login for Business. Ads are created paused in Ads Manager — you turn them on after review.

          Setup notes

          Skip Settings → Advanced → Domain Manager and skip App domains for local use (Meta rejects localhost / 127.0.0.1 there). Skip App authentication → Authorize callback URL. In Settings → Basic add a Website platform with Site URL https://localhost:8765/. Then open Facebook Login for Business → Settings, turn on Client OAuth Login and Web OAuth Login, and add https://localhost:8765/api/oauth/callback Facebook Login is blocked in AdsPower and other antidetect browsers (Google sign-in does not help). Connect once in normal Chrome with the same Google account, or paste an EAA… token from Graph API Explorer. If you need a different Facebook user, add them as Tester/Developer under Meta App Roles — Development mode only allows people with a role.

          Server is missing META_APP_ID / META_APP_SECRET in .env (local) or Wrangler secrets (deploy). Also set META_REDIRECT_URI to https://localhost:8765/api/oauth/callback. Restart the Python server after saving.
